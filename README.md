# HR Analytics Dashboard

An interactive HR Analytics Dashboard built using Power BI to analyze employee data and generate meaningful workforce insights.

## 📌 Features

- Employee Attrition Analysis
- Department-wise Employee Distribution
- Salary and Job Role Insights
- Age Group & Gender Analysis
- Workforce Trend Visualization
- Interactive Power BI Dashboard

## 🛠️ Tech Stack

- Power BI
- CSV Dataset
- Data Visualization
- Data Analytics

## 📂 Project Files

- `HR-Analytics-Dashboard` → Main Power BI dashboard file
- `HR_Analytics.csv` → Dataset used for analysis

## 📊 Dashboard Insights

This project helps organizations:

- Understand employee attrition patterns
- Analyze workforce demographics
- Track department performance
- Improve HR decision-making using data

## 🚀 How to Use

1. Download the `.pbix` file
2. Open it in Power BI Desktop
3. Load the dataset if required
4. Explore the interactive dashboard
